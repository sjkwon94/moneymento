# 자산허브 알림 앱 (안드로이드)

올원뱅크·케이뱅크 입출금 알림을 감지 → 확인 팝업(수정/확인/보류) → 서버 가계부로 전송하는 앱.
안드로이드 스튜디오 없이 GitHub에서 APK를 빌드해 받습니다.

## APK 받는 법 (PC에 아무것도 설치 안 함)

1. github.com 로그인 → 우측 상단 **+** → **New repository**
   - 이름 아무거나 (예: `noti-app`), **Private** 선택, Create
2. 만들어진 저장소에서 **uploading an existing file** 링크 클릭
3. 이 폴더(noti-app)의 **모든 파일·폴더를 통째로 드래그**해서 올리고 **Commit changes**
   - `.github`, `gradle`, `gradlew` 파일까지 빠짐없이 올려야 합니다
4. 상단 **Actions** 탭 → "Build APK" 워크플로가 자동 실행 (5~10분)
5. 초록 체크가 뜨면 그 실행을 클릭 → 하단 **Artifacts** → **app-debug-apk** 다운로드
6. 압축 안에 `app-debug.apk` → 폰으로 옮겨 설치 (알 수 없는 출처 허용 1회)

빌드가 실패(빨간 X)하면 실행을 눌러 로그를 확인하거나 그대로 캡처해 문의하세요.

## 설치 후 설정 (앱에서)

1. **서버 주소**: `http://68.183.181.222` (기본값)
2. **알림 토큰**: 서버 `.env` 의 `NOTIF_TOKEN` 과 똑같이 입력
3. **설정 저장 + 연결 테스트** → "연결 성공" 확인
4. 권한 3가지 순서대로 허용:
   - 알림 접근 (필수)
   - 다른 앱 위에 표시 (필수 — 오버레이 팝업용)
   - 배터리 최적화 제외 (권장 — 백그라운드 유지)
5. **오버레이 서비스 시작** 버튼 1회

## 동작

- 은행 입출금 알림 → 즉시 오버레이 팝업
- 팝업에서 **금액·분류·입출금 구분** 수정 가능
- **확인**: 값 확정 후 서버 전송 · **보류/홈버튼**: 큐에 남겨 30분 뒤 재확인
- 확정 건만 서버 가계부에 기록되고, 계좌명이 맞으면 잔액도 증감

## 서버 준비 (한 번만)

`.env` 에 토큰 추가 후 재시작:
```
NOTIF_TOKEN=<openssl rand -hex 24 로 생성한 값>
```
```bash
systemctl restart asset-hub
```

## 파싱 정확도

은행 알림 문구는 형식이 다양해 일부 거래는 잘못 파싱될 수 있습니다.
그래서 매 건 확인 팝업으로 사람이 검수하는 구조입니다. 자주 틀리는 패턴이 있으면
`app/src/main/java/com/assethub/notifier/TxParser.kt` 의 정규식을 조정하세요.
